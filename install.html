LLM-GTD

A Getting Things Done board where you capture and decide, and Claude does the filing — every item is a plain markdown note, the board just renders it.

The idea

Karpathy's llm-wiki pattern splits knowledge work into three layers — raw sources, an LLM-maintained wiki, and a schema that governs it — with two operations on top: ingest new material, lint the whole thing for rot. Applied to a task inbox instead of a wiki, ingest becomes triage and lint becomes review. The whole system is six plain files: no server, no database, no Notion API — an Obsidian vault, a schema doc, and a handful of Claude Code skills.

Capture from your phone or a web clipper without thinking about where it goes. Four routines keep the boards honest:

/gtd:triage

Empties the inbox — summarizes clipped links, reuses your existing tags, proposes a column for each item, waits for your yes.

/gtd:review

The weekly lint pass — flags what's gone stale, archives old done items, resurfaces someday.

/gtd:project

For the outcomes that need more than one action — a renovation, a house purchase, learning a skill. It agrees what "finished" means, breaks the rest into steps small enough to start, and then puts one of them on the board. The other nineteen wait as a checklist in the project note, because a plan rendered as twenty cards is a plan nobody starts. Run it with no argument and it advances every project you have.

/gtd:pocket

GTD holds things to do; Pocket holds things to keep. Read an article, drag it to done, and if it's worth keeping, /gtd:pocket moves it to a separate board where the columns are categories you choose, with its own tags. Or clip straight into Pocket and let it file the note later. Already have a folder full of saved articles? /gtd:pocket-import <folder> goes through it with you and moves only what's worth keeping.

Coming from somewhere else? A second prompt, import-notion.md, loads a Notion Markdown & CSV export (or any CSV) onto the board — it surveys the export, proposes how your old statuses and tags map onto these six columns, and writes nothing until you say yes. Drop the zip in a .gtd-import/ folder at the vault root and it finds it by itself; the leading dot keeps Obsidian from indexing the export. It's a paste-in prompt rather than an installed command, because importing happens once.

Try it yourself

  1. Install Obsidian, make a new empty vault.
  2. Settings → Community plugins → enable, then install: Base Board Templater. Enable both. (Base Board needs Obsidian 1.10.2 or newer.)
  3. Settings → Templater → turn on Trigger Templater on new file creation and add a Folder Template: GTD/Items → Templates/GTD Item.md, so hand-made notes auto-fill their frontmatter. (Nothing else to style — Base Board draws the cards itself, and the prompt writes nothing into .obsidian/.)
  4. Install Claude Code, open a terminal at the vault's root folder.
  5. Run the two commands below there. The first installs the gtd plugin for this vault only; the second writes the schema, templates and boards.
  6. Open GTD/Board.base — that's your kanban. Capture a thought, then run /gtd:triage whenever the inbox looks full. Something too big for one card? /gtd:project turns it into a plan and puts the first step on the board.

Install

LLM-GTD is a Claude Code plugin. It works on a fresh vault or an existing one: everything it writes lives under GTD/ and Pocket/ plus two templates and clipper/, and it stops rather than overwrite anything already there.
