LLM-GTD

A Getting Things Done board where you capture and decide, and Claude does the filing — every item is a plain markdown note, the board just renders it.

The idea

Karpathy's llm-wiki pattern splits knowledge work into three layers — raw sources, an LLM-maintained wiki, and a schema that governs it — with two operations on top: ingest new material, lint the whole thing for rot. Applied to a task inbox instead of a wiki, ingest becomes triage and lint becomes review. The whole system is six plain files: no server, no database, no Notion API — an Obsidian vault, a schema doc, and two Claude Code skills.

Capture from your phone or a web clipper without thinking about where it goes. Two routines keep the board honest:

/gtd-triage

Empties the inbox — summarizes clipped links, reuses your existing tags, proposes a column for each item, waits for your yes.

/gtd-review

The weekly lint pass — flags what's gone stale, archives old done items, resurfaces someday.

Coming from somewhere else? A second prompt, import-notion.md, loads a Notion Markdown & CSV export (or any CSV) onto the board — it surveys the export, proposes how your old statuses and tags map onto these six columns, and writes nothing until you say yes. Drop the zip in a .gtd-import/ folder at the vault root and it finds it by itself; the leading dot keeps Obsidian from indexing the export. It's a paste-in prompt rather than an installed command, because importing happens once.

Try it yourself

  1. Install Obsidian, make a new empty vault.
  2. Settings → Community plugins → enable, then install: Dataview Templater Kanban Base Board Tasks Icon Folder. Enable all six. (Base Board needs Obsidian 1.10.2 or newer.)
  3. Settings → Templater → turn on Trigger Templater on new file creation and add a Folder Template: GTD/Items → Templates/GTD Item.md, so hand-made notes auto-fill their frontmatter. (Card styling is handled automatically — the prompt writes and enables a small CSS snippet; reload Obsidian once if labels still show.)
  4. Install Claude Code, open a terminal at the vault's root folder.
  5. Paste the prompt below into Claude Code and let it write the schema, template, board, and skills.
  6. Open GTD/Board.base — that's your kanban. Capture a thought, then run /gtd-triage whenever the inbox looks full.

The bootstrap prompt

Self-contained — it embeds the full schema, so Claude Code can write every file from scratch, no repo access needed. Works on a fresh vault or an existing one: it's all namespaced under GTD/, and the prompt merges into rather than overwrites a vault that already has content.
